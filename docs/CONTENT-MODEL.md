# 数据模型：从卦、爻到经传

## 收录边界

| 结构 | 数量 | 文本性质 |
| --- | ---: | --- |
| 六十四卦 | 64 | 文王卦序，上经30、下经34 |
| 卦辞 | 64 | 《易经》经文 |
| 六爻辞 | 384 | 《易经》经文，64×6 |
| 乾用九、坤用六 | 2 | 特殊经辞，不能算作常规384爻之一 |
| 彖传 | 64 | 《易传》，另层 |
| 大象传 | 64 | 《易传》，另层 |
| 小象传 | 384 | 《易传》，另层 |

经层需要被阅读的共64+384+2=450个文本单元。**独立《系辞》《说卦》《序卦》《杂卦》《文言》尚未收为全文**，不能称作完成《十翼》所有篇章。

## 每卦字段

number、name、fullName、symbol、upper、lower、upperNature、lowerNature、bits、judgment、judgmentGloss、tuan、image、lines[]、specials[]、sourceUrl、sourceRevision。

lines按初、二、三、四、五、上排列；每项包含index、label、text（古文）、smallImage（传文）、gloss（现代释读）。现代释读主要源于CC BY-SA 4.0的DaviRain-Su / Classical Atlas，不能与古人语句混写。

## 数据运算约定

- 下卦乾111、坤000、兑110、离101、震100、巽011、坎010、艮001。
- 上卦与下卦相重成6位。六位编码必须覆盖全部64种组合，没有重复。
- 改一爻=只翻转第1—6位之一，64×6=384条有向结构关系；反复改变同一爻应恢复本卦。
- 错卦=全部六位反转；综卦=六位顺序颠倒，两操作都为对合（做两次回到原卦）。
- 数据内容不用于预测现实概率。历史象数的阐释有多种学派，不能把现代网页算法当唯一解释。
