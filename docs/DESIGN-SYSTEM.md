# 设计系统：丝绢、矿物色与青铜圆环

## 视觉方向

不与《道德经》的山水水墨、《孙子兵法》的青铜武备以及《论语》的竹影重复，《周易》强调**六爻线条、阴阳圆环、丝绢纸面与青铜矿物色**。大字号宋体强调经典，现代系统无衬线字体负责导航和交互。

## 页面结构

- 首页：大字“周易。”、圆环、阴阳示意与引文“穷则变，变则通，通则久”（出《系辞下传》）。
- 三种阅读线索：观象、读辞、识变。
- “天行健”作为明确标注乾卦大象传的独立展陈。
- 64卦目录：大屏八列，逐级缩成六/四/三列；点击直接到阅读室。
- 阅读室：左侧64卦列表，右侧卦象互动和经传文献；手机卦目改为横向滚动条，原文与白话始终单列上下布局。

## 可访问性和动效

使用原生button、details、summary和focus-visible；六爻按钮带aria-pressed状态和准确的上/下爻标签。尊重prefers-reduced-motion，不因禁动而隐藏页面内容。不得加载未经授权的字体、头像或图像资源。
