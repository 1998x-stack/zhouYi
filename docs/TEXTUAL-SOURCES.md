# 文献底本、异文与现代导读来源

## 固定的文本来源

1. 古代经、彖、大小象：逐卦电子原文参考 [toastedqu/meihua](https://github.com/toastedqu/meihua) 项目app/data/classics.json，其经传采自维基文库《周易》64卦页面，并附上**逐卦来源URL和修订号**。源档不收乾坤用九、用六。
2. 用九/用六以及相应小象：补自 [ZQing-Chen/yijing](https://github.com/ZQing-Chen/yijing) 的assets/data/gua64.json公版文本。
3. 现代卦辞、爻辞导读：来自 [DaviRain-Su/classic_system](https://github.com/DaviRain-Su/classic_system) 的hex-gloss.ts和data.ts，原项目声明原创解释文字采用**CC BY-SA 4.0**。许可与署名详见../CONTENT-ATTRIBUTION.md。

## 经与传

《易经》是卦辞、爻辞等早期文本；《易传》为后世传文的集合，包括《彖》《象》《文言》《系辞》《说卦》《序卦》《杂卦》等。文字成书分层、作者归属和各文本时代都有学术讨论。本站将每卦的彖、大小象单独存储和显示，不将“天行健”“地势坤”误称乾坤卦辞。

## 其他版本的后续研究

王弼本、朱熹《周易本义》、帛书《周易》与通行文王卦序的异文和次序并非可以未经校核地替换。今本标点来自电子转录和后人整理；先秦早期原貌有待考据。

优先针对文本中涉及礼制、政治、古典战争、占筮吉凶、身份和性别角色之处审查现代解说的偏差。不得把过去的身份等级规范或古代断语当成今天的法律或道德唯一标准。

## 校勘与许可

文本修订需要特定电子修订号/刊本、位置、原文字形、异文、解释差异与审校证据。现代白话应注明可能存在解释争议、非唯一译法，并按CC BY-SA保留原作者署名及同方式共享。
