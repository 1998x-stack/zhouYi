# 质量验证与独立验收

## 自动检查：npm test

- 64个文王卦序编号、对应64个不同6-bit符号。
- 上经1—30，下经31—64；八卦3-bit编码均唯一。
- 64卦辞、384正常爻辞、乾坤各1特殊经辞，合450项经文。
- 64条彖传、64条大象传、384条小象传皆非空。
- 每卦卦辞、六爻都有独立现代导读、每卦原文URL与修订号。
- 下爻索引0、上爻索引5，阴阳翻转384种结果均有效并具有对合性质；错卦与综卦做两次回到原卦。
- HTML必须为唯一ID，JS使用正确DOM ID、translation.hidden=true、aria-expanded、aria-controls和独立经传区域。
- 所有动态文字不使用innerHTML；静态构建包含所有JS数据包与字体无依赖SVG。
