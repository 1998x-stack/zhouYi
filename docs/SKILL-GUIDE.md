# zhouyi-wisdom：如何正确地“以易思事”

《周易》中的“时、位、变、恒、止、行”可以用于帮助辨认现实中的决策条件，但不能直接作为任何未来事件必然发生的证据。

## 五步框架

- 辨事：先看现实目标、证据、约束、参与者、代价和权利。
- 观象：挑选和问题确有关联的卦辞、爻辞或后来的易传思想。
- 引辞：引用真实短句、卦名与爻位/卦辞/大象传等层次。
- 释义及界限：解释古代意象为何能启发思考，哪些地方不可直接照搬。
- 行动：给1—3个现代合法安全的步骤与可验证指标。

## 正确引用范例

**“项目刚开始，是否应全面押注？”**

「潜龙勿用。」——《周易·乾·初九》。

释义：初爻仍处潜藏阶段，传统义理多用以提醒人辨别实力与时机。对应新项目，启发是把试错范围与已验证的证据相匹配，并非预测将来一定失败。

行动：提出一个小规模可逆试点，事先确定质量、时间、收益以外的风险阈值和停止标准；根据反馈决定是否加大投入。

## 易经／易传常见错引

- “天行健，君子以自强不息。”出乾卦大象传，不是《乾》卦辞。
- “穷则变，变则通，通则久。”出《系辞下传》，当前数据库尚未全文收录，不能虚构文王六十四卦序号。
- 历史术语“吉凶、悔吝、无咎”不能用于确定当下健康、投资或人际结果。
