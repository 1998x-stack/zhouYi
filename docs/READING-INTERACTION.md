# 逐条经辞与隐藏的现代导读

## 阅读结构

每卦的经文阅读区域：一条卦辞 → 六条从下到上的爻辞 → 若为乾坤，最后附用九/用六。每个独立单元都有可见原文、对应的独立语义button与**真实hidden的现代白话**，不以blur假装隐藏。

点击A的“轻触见义”只开启A的白话；再次点击收起；点击“收起全部”关闭本卦已打开的内容；切到任何新卦所有导读恢复遮挡。字号更改只改--reading-font，不改变打开状态。

按钮必须含aria-expanded与aria-controls，译文DOM id由卦序号与文本单元序号确定，切卦时不重复。现代白话导读来自第三方，有完整署名，不得混入古文原句。

## 六爻可视化

数值编码bits从下往上，六爻图从上往下视觉排列，所以页面上第一个按钮对应第6位（上爻），最底一个按钮对应第1位（初爻）。阴爻为两段、阳爻为整段。点击翻转单爻只更新**结构关系预览**；“阅读该卦”才真正导航到对应卦，不声称这代表未来演化结果。

错卦为取反，综卦为倒序。自反关系需正常显示本卦。

## 经传分层

《彖传》《大象传》《小象传》位于独立details区域；它们不与卦辞、爻辞串接，也不冒充已有逐句译文。未来引入传文白话必须提供相同的准确出处、授权和一一对应结构。
