# 产品定位 · 观变知时

## 核心目标

将《周易》作为传统文化与思想经典进行严肃阅读，而不是把六十四卦伪装成对现代个人命运的科学预测。用户能够通过卦爻辞、易传与阴阳结构认识“时、位、变、守正”的思想，结合现代证据理性决策。

## 目标读者与旅程

1. 从64卦目录寻找卦名，也可以检索原文、彖象与现代白话。
2. 进入阅读室，查看上经/下经与卦象、上下八卦、从下到上的六爻。
3. 不先看到现代白话，独立阅读卦辞和各爻后再逐条点击揭晓。
4. 在独立的《彖》《象》原典层看古人的解释，理解经与传的成书差别。
5. 翻转任一阴阳爻，观察确定的另一卦结构；可查看错卦/综卦并继续阅读。
6. 用zhouyi-wisdom Skill，借古典思想分析具体项目、学习与合作问题；讨论不替代事实核查。

## 当前不做

不提供确定吉凶预报、个人命运诊断、盈利预测、博彩引导；不把所有《十翼》称作当前已收录；不要求用户注册，不追踪用户行为，不用未经授权的现代译注。
