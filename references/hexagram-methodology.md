# 文王卦序、六爻方向与符号运算

八卦和六十四卦都是可以明确编码的古代符号结构。本站采用稳定的六位二进制标识（阴0，阳1），**第0位为初爻（最下面），第5位为上爻（最上面）**：

- 乾 = 111；坤 = 000；震 = 100；巽 = 011；坎 = 010；离 = 101；艮 = 001；兑 = 110。
- 六卦由下卦三位在前、上卦三位在后连接。例如天水讼：下坎010、上乾111，编码010111。
- 64卦必须各有唯一的六位编码。通过任一爻翻转0/1即可确定另一卦，共64×6=384种“原卦·变化爻”操作。
- 错卦（六位取反）：每一爻阴阳全反。综卦（六位倒序）：上下颠倒，注意部分卦自反。
- 不根据特定卦或结构变换给当下现实风险分数、金融回报率、疾病诊断等实际预测数值。

## 经传分层

《易经》经层：卦辞64，常规爻辞384，乾坤另有用九/用六两项。传层：彖64、大象64、小象384。独立《系辞》《说卦》《序卦》《杂卦》《文言》尚需另建版本资料。
