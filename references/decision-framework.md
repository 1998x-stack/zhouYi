# 现代决策中的易学反思框架

## 五步

1. 事实：我的目标是什么？掌握哪些证据？有哪些未知？
2. 象义：与处境相关的是新生困难、等待、协调、发展、节制还是变革？
3. 经传：选一两句真实原文，写清《周易·卦名·位置》及经传差别。
4. 边界：古代象义是类比，不等于对未来的科学因果结论；今天的伦理、法律与安全优先。
5. 行动：设计一个现实可验证的小步行动与观察指标。

## 模板

- “乾·初九”：准备与试点。行动建议：关键假设、成功阈值与退出条件。
- “坤·初六”：风险识别。行动建议：找到小的先行指标，设置早期预警。
- “乾·上九”：防止骄满。行动建议：增加独立复盘和退出/纠偏空间。
- “既济·大象传”：成功后的维护。行动建议：建立事件回顾、运维检查与责任人制度。

禁止用卦象推断他人动机、健康、财富、爱情结果或项目将来一定成败。
